# 東暦人生録 — TOREKI LIFE

東暦世界を舞台にしたブラウザ人生シミュレーションです。

- 21か国からの出生ガチャと国別ランダム名
- 73種類のイベント、一年に4回の選択
- 事故・療養・回復、就職・移住・人間関係
- 自動保存、過去の人生録、ログ検索とテキスト／JSON書き出し

## 遊び方

`index.html` をブラウザで開くか、GitHub Pagesで公開してください。ビルドや依存パッケージは不要です。

ゲームの進行と人生録はブラウザの localStorage に保存されます。別端末・別ブラウザとは同期しません。

## ファイル

- `index.html`: ゲーム画面
- `style.css`: スタイル
- `game.js`: ゲームとイベント、ログ、保存処理

## 世界設定

[東暦ワールドポータル](https://ec2045.github.io/)の公開資料および提供された世界地図を参照しています。詳しい参照先はゲーム内の「設定と参照資料」を参照してください。

人物の生成名、イベント、確率、生活ポイント、職業・移住条件などにはゲーム独自の仮設定を含みます。同名の現実の国の地理や制度をそのまま再現したものではありません。
