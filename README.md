# 東暦人生録 — TOREKI LIFE

東暦世界の人生シミュレーション。日常をまとめて進め、重要な場面で選択します。

- 21か国の出生ガチャと国別の名前
- 日常の自動進行、進路・事故・体質などの重要な選択
- 国別通貨、年ごとの収支、買い物、移住時の両替
- 国ごとの生物との出会い、種族を持つ友人、ハーフ・吸血鬼の珍しい出生
- 自動保存、検索可能なログ、過去の人生録、テキスト・JSON書き出し

`index.html` をブラウザで開くか、GitHub Pagesで公開してください。ビルドは不要です。セーブはブラウザのlocalStorageに保存され、旧バージョンの進行も引き継ぎます。

## 通貨

和温陣国は 1 テクトニクス = 10,000 erias。ユーザー提供の価格はパン2〜5 erias、水1 erias、普通の食事10〜30 erias、服50〜200 eriasです。

日本は円、onvaは !abyaren。公開資料の !abyang = 0.55 !abyaren、おにぎり2 !abyang、ONVAのPC420 !abyarenも参照しています。その他の国の通貨は未確定のため国別の仮単位を使います。換算・収入・生活費はゲーム用の固定設定で、ライブ為替とは連動しません。

## 生物

onvaのコロレン・スイレン・ネルン、和温陣国の双角の白鳥蜘蛛・電位殻の重歩蝸を各国の公開資料から採用しています。知的種族は地域の住民・友人として登場します。ハーフ2.5%、吸血鬼1%の独立した出生抽選や暮らしの特性はゲーム上の仮設定です。

詳しい参照先はゲーム内の「設定と参照資料」を参照してください。

## 寿命と人生の終わり

80歳で終了する制限はありません。どの年齢でも重大事故や病気で亡くなる可能性があり、年齢と健康状態に応じて経過が変わります。80歳以降も日常の出来事・収支・交流が続きます。吸血鬼の緩やかな加齢や、デジタル存在の記憶障害もゲーム用の仮設定で、公式な種族の寿命や現実の死亡率を再現していません。

死亡時は年齢・原因を人生録に残し、その場で自動進行を止めます。旧版の80歳での機械的な区切りに達した現在のセーブは、続きから進められます。死亡した人生と、過去の人生録は復活・削除しません。

## 国と地域

出生ガチャでは国と地域を抽選します。和温陣国の居住区分は[公式ポータルの国勢調査欄](https://ec2045.github.io/Waon-Jinkoku/#tab-overview)、IFECIの3州は[政府ポータルの州一覧](https://ec2045.github.io/ifeci/#states)を参照しています。日本の渋谷区セクター7Gは[NODE LABの沿革](https://ec2045.github.io/NODE-LAB/)に基づきます。地域名の資料がない国では都市部・住宅地域・郊外をゲーム内区分として使います。

成人後は州や都市を指定して国内外に移住できます。首都外への許可証申請、地域別の生活費、地域イベントの内容はゲーム内の扱いです。旧セーブでは出生・居住の地域を未記録のまま引き継ぎます。

## 家族・交流・自動進行

出生時に保護者の仕事と年齢、住まい、家計、きょうだい、勉強環境が決まります。21か国それぞれに36人のゲームオリジナル住民がいます。onvaと和温陣国では公開資料に載っている東暦の人物25人も登場します。再会や交流で関係を育て、成人した友人とは双方の気持ちが合えば交際に進めます。旧版の人物名と関係は過去のログに残ります。

「1年ずつ自動で進める」をオンにすると、一年単位で進行し、選択が出ると止まります。選択後に再開し、途中でオフにもできます。

参考資料は[80億分の1](https://1in8b.life/ja/)、[onva国籍名簿](https://ec2045.github.io/onva-citizen/)、[和温陣国公式サイト](https://ec2045.github.io/Waon-Jinkoku/#tab-database)です。
